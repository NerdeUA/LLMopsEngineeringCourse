# HW1 implementation plan

**Goal:** Complete [HW1](../../../homework/hw1.md) with a database prompt registry and request provenance.

**Architecture:** Keep the existing .NET minimal API and Npgsql. Seed the `support` prompt in SQL; read its active body and version together for each chat. Use a transaction and a table lock for activation, and a partial unique index for one active version per name. Fall back to `You are an assistant.` / `none` when no active prompt is available. Keep the existing UI contract.

**Tech stack:** .NET 8, Npgsql, PostgreSQL 16, Docker Compose, Python standard-library integration tests.

**Spec:** `homework/hw1.md`, `homework/CHECKS.md#hw1`.
