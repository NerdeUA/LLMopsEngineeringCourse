# HW2 implementation plan

**Goal:** Complete routing and cost criteria in `homework/hw2.md` and `homework/CHECKS.md#hw2`.

**Architecture:** Keep the existing minimal API. Add a small `ModelPolicy` containing bilingual escalation markers, mock USD prices per 1,000 input/output tokens, and decimal cost calculation. Default `MODEL=mock` enables routing; an explicit model override retains the starter's manual model selection. Unknown model pricing remains unknown (`NULL`) rather than fabricated. `/cost` queries persisted costs for the database's current calendar day and returns a configured daily budget (default USD 10).

**Scope:** Mock-only deterministic prices, not real provider tariffs. No retries or fallback execution until HW4; record the full fallback order beside routing. No UI changes or new dependencies.
